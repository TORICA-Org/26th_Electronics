# 取得したいデータ

データフォーマット
```
data_(測定場所)_(使用センサの略称)_(データの種類)_(単位)
```

<br>

- 「使用センサ」の列について，直接測定できる値は無印，複数の値を用いて算出する値はカッコ`()`つきです．
- 「測定対象」の列について，複数の値を用いて算出する場合，算出に用いた値をカッコ`()`内に示しました．
