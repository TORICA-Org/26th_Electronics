# センサやマイコン間の通信

聞かれることの多かった，しかしながら最も重要な要素である，「通信」についてまとめます．（00kenno）

<br>

## 通信の種類

|種類|通信速度(bps)|通信線数|通信距離|リレーション|使用例|
|:--:|:--:|:--:|:--:|:--:|:--:|
|UART|中速(9.6k\~1M)|2本|\~数百m|1対1|基板 - 基板|
|I2C|中速(100k\~3.4M)|2本|\~1m|1対多|マイコン - センサ(基板内)|
|SPI|高速(1M\~10M)|4本|\~0.5m|1対多|マイコン - SDカード(基板内)|

<br>

### UART
ArduinoIDEを使ったマイコンのプログラミングにおいて，最も基本的な通信です．  

- 追加ライブラリが不要です．
- VCCとGNDを含めても線数は4本で済みます．

以下はArduinoIDEによるソフトウェアのサンプルです．

<br>

送信側
```cpp
void setup() {
  Serial1.setTX(0);
  Serial1.setRX(1);
  Serial1.begin(115200);
}

void loop() {
  Serial1.println("Hello, world!");
}
```

<br>

受信側
```
void setup() {
  Serial1.setTX(0);
  Serial1.setRX(1);
  Serial1.begin(115200);

  Serial.begin(115200); // シリアルモニター
}

void loop() {
  if (Serial1.available() > 0) {
    String str;
    str = Serial1.readStringUntil('\n');
    Serial.println(str); // -> Hello, world!
  }
}
```

<br>

### I2C
同基板上にある1つのマイコンと複数のセンサとの間でこの通信が用いられることが多いです．

- 複数のスレーブで信号線(SDA, SCL)を共有することができます．
- 「マスター（主人）」と「スレーブ（奴隷）」という概念があります．
- `Wire`ライブラリを用いて制御できます．

以下はAS5600を接続して値を読み取る場合を想定したソフトウェアのサンプルです．
（[公式サンプル](https://www.switch-science.com/products/3493?_pos=2&_sid=d9c1e74eb&_ss=r)に一部加筆しています．）
一般的に，センサとの通信は「レジスタアドレスを送信」➔「それに応じた値をセンサICが返す」という流れになっています．
（これが少し難解だから，I2C通信を簡単な関数で終わらせるための様々なライブラリがたくさんあるわけです．）

<br>


```cpp
#include <stdint.h>
#include <Wire.h>
#define AS5600_AS5601_DEV_ADDRESS      0x36
#define AS5600_AS5601_REG_RAW_ANGLE    0x0C

void setup() {
  Wire.setSDA(4); // SDA（データ）ピン設定（※必ず通信開始前に設定）
  Wire.setSCL(5); // SCL（クロック）ピン設定（※必ず通信開始前に設定）
  Wire.begin(); // 通信の開始
  Wire.setClock(400000); // 通信のクロックを指定（※必ず通信開始後に設定）

  Serial.begin(115200);
}

void loop() {
  // Read RAW_ANGLE value from encoder
  Wire.beginTransmission(AS5600_AS5601_DEV_ADDRESS); // 通信の開始
  Wire.write(AS5600_AS5601_REG_RAW_ANGLE); // レジスタアドレスを送信
  Wire.endTransmission(false); // 通信を終了しない
  Wire.requestFrom(AS5600_AS5601_DEV_ADDRESS, 2); // 2byteのデータを待ち受け
  uint16_t RawAngle = 0;
  RawAngle  = ((uint16_t)Wire.read() << 8) & 0x0F00; // ビット演算
  RawAngle |= (uint16_t)Wire.read(); // ビット演算
  // Raw angle value (0x0000~0x0FFF) is stored in RawAngle

  Serial.print("Raw angle value = ");
  Serial.println(RawAngle);
  delay(200);
}
```

### SPI
鳥科の電装では，通信速度が必要とされる マイコン ↔ SDカードモジュール 間の通信に使用しています．
> [!NOTE]
> なぜSDカードモジュールとの通信が高速である必要があるのか？
> スループット（データ転送量）を確保しないと，SDカードの性能を引き出せない（書き込みをデータが来るまで待つことになる）だけでなく，SDカードモジュールとの通信が終了するまでに，次のデータが来てしまうためです．

以下はSDカードへ一度だけテキストファイルを書き込むソフトウェアのサンプルです．
鳥科では，`.txt`となっているのを`.csv`としてデータを保存しています．

<br>

```cpp
#include <SPI.h>
const int _CS = 1;
const int _SCK = 2;
const int _MOSI = 3;
const int _MISO = 4;

#include <SD.h>
File myFile;

void setup() {
  SPI.setCS(_CS);
  SPI.setSCK(_SCK);
  SPI.setTX(_MOSI);
  SPI.setRX(_MISO);
  SPI.begin();

  SD.begin(_CS);

  myFile = SD.open("test.txt", FILE_WRITE);

  // if the file opened okay, write to it:
  if (myFile) {
    Serial.print("Writing to test.txt...");
    myFile.println("testing 1, 2, 3.");
    // close the file:
    myFile.close();
    Serial.println("done.");
  } else {
    // if the file didn't open, print an error:
    Serial.println("error opening test.txt");
  }
}

void loop() {}
```
